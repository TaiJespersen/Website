# ⚡ NANOGrav & Pulsar Astrophysics Portfolio (Videogame Edition)

An interactive, videogame-styled personal website for an astrophysics researcher specializing in **Neutron Stars, Millisecond Pulsars, and the NANOGrav (North American Nanohertz Observatory for Gravitational Waves) Collaboration**.

Designed with a low-poly flat-shaded retro-sci-fi aesthetic, built with **ReactJS, HTML5, CSS3, Three.js, and procedural Web Audio**, and structured to deploy directly to **GitHub Pages** as static files without any build steps or server runtime.

---

## 🚀 Live GitHub Pages Deployment Guide

This project is 100% static and uses relative paths (`./`), making it immediately compatible with GitHub Pages:

### Step 1: Initialize a Git Repository
```bash
cd /Users/tai/.gemini/antigravity/scratch/astrophysics-portfolio
git init
git add .
git commit -m "Initial commit: NANOGrav low-poly astrophysics videogame portfolio"
```

### Step 2: Push to GitHub
Create a new public repository on [GitHub](https://github.com/new) (e.g. `astrophysics-portfolio` or `<your-username>.github.io`), then run:
```bash
git remote add origin https://github.com/<your-username>/astrophysics-portfolio.git
git branch -M main
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. In your GitHub repository, navigate to **Settings** > **Pages** (under "Code and automation").
2. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` / `/ (root)`
   - Click **Save**.
3. Within 1–2 minutes, your website will be live at:
   `https://<your-username>.github.io/astrophysics-portfolio/`

## 🌌 Star System Sectors & Scientific Content

1. **Sector 1: PSR J1713+0747 (Millisecond Pulsar)**
   - High-precision cosmic clock (4.57 ms period).
   - NANOGrav 15-Year Data Set overview: evidence for the nanohertz stochastic gravitational wave background.
   - **Pulsar Audio Sonification**: Listen to the actual acoustic frequency generated by millisecond pulsars spinning at 218.8 Hz!

2. **Sector 2: PSR B1913+16 (Hulse-Taylor Binary System)**
   - Twin orbiting neutron stars with expanding low-poly gravitational wave ripple waves.
   - Peer-reviewed publications browser with topic filtering (*NANOGrav/PTA*, *Neutron Stars*, *Algorithms/GPU*), arXiv links, and 1-click BibTeX citation copying.

3. **Sector 3: Magnetar SGR 1806-20 (Interactive Physics Labs)**
   - **Hellings-Downs Correlation Simulator**: Interactive angular separation slider $\theta$ calculating Einstein's quadrupolar correlation function $\mu(\theta)$ alongside synthetic NANOGrav 15-year data points with 1-$\sigma$ error bars.
   - **Interstellar Plasma DM Dedisperser**: Dynamic multi-channel radio frequency waterfall (1.2–1.8 GHz) where you dial in the Dispersion Measure (DM) to correct plasma time delay and resolve sharp pulses.

4. **Sector 4: Green Bank & Arecibo Array (Observatory Relay)**
   - Dr. Lyra Mercer's academic dossier, telescope time allocations (GBT 100m, CHIME, VLA, NICER), appointments, and printable CV export.

5. **Sector 5: Earth Deep Space Relay (Contact)**
   - Interactive sub-space message transmission console.
   - Direct academic links: Email, ORCID, Google Scholar, GitHub, and arXiv.

6. **2D Accessible Reader Mode**
   - Click **"📄 2D READER MODE"** in the top HUD to instantly switch from 3D WebGL to a clean, high-contrast, text-first archival view suitable for screen readers or low-power hardware.

## 🛠️ Customizing the Researcher Portfolio

To customize the website for yourself or another researcher:
1. Open [`js/data.js`](./js/data.js).
2. Edit `AstroData.researcher` with your name, institution, bio, stats, and telescope allocations.
3. Update `AstroData.publications` with your own papers, DOIs, arXiv IDs, and BibTeX citations.
4. Update `AstroData.teaching` and `AstroData.outreach` with your courses and lectures.
5. Push to GitHub, and your personal site updates automatically!
