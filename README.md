## Videogame Controls
| Input | Action |
|---|---|
| **W / Up Arrow** | Forward Thruster (Throttle) |
| **S / Down Arrow** | Reverse / Decelerate |
| **A / D or Left / Right** | Turn Ship (Yaw & Banking Roll) |
| **Shift** | Turbo Boost (Increased Velocity & Audio Pitch) |
| **Space** | Inertial Space Brake |
| **E / Click Prompt** | Dock / Scan Celestial Body (Open Research Modal) |
| **1 – 5** | Fast-Travel Hyperspace Jump to Celestial Sector |
| **M** | Toggle Audio (Procedural SFX & Ambient Synth Drone) |
| **ESC** | Close Active Modal Dialog |
| **Mobile Touch** | Virtual On-Screen D-Pad, Boost & Dock Buttons |
